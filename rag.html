What this simulates
This is an educational RAG pipeline. Embeddings and similarity scores are approximated in-browser so you can see the concepts without an API key.
● Retrieval-Augmented Generation

See what happens inside a RAG system, step by step.

Add source material, split it into chunks, create simulated embeddings, index the chunks, ask a question, retrieve the most relevant context, rerank it, build an augmented prompt, and generate a grounded answer with citations.
